EnergiCast

Energy Consumption Forecasting System

Versi 1.0 | Demo Akademik

Tujuan Proyek

  • Mengimplementasikan workflow forecasting time-series menggunakan LSTM (Long Short-Term Memory)
  • Menyajikan eksplorasi data, hasil preprocessing, training, evaluasi, dan forecasting dalam web UI yang interaktif
  • Menjadikan proyek mudah dijalankan secara lokal, dipelajari, dan dipresentasikan sebagai portofolio
  • Menyediakan struktur kode modular, dokumentasi, pengujian, serta reproducible workflow

Dataset

Sumber: Individual Household Electric Power Consumption (Kaggle / UCI)

Target: Global_active_power (kW)

Frekuensi Asli: Per menit

Frekuensi Baseline: Hourly (rata-rata per jam)

Fitur: Date, Time, Global_active_power, Global_reactive_power, Voltage, Global_intensity, Sub_metering_1/2/3

Batasan & Catatan

  • Demo Akademik: Aplikasi ini untuk pembelajaran dan demonstrasi, bukan sistem pengendalian listrik atau keputusan operasional
  • Tidak Mengklaim Akurasi: Prediksi adalah estimasi berbasis model, bukan nilai aktual atau jaminan akurasi
  • Single Household: Dataset hanya mencakup satu rumah tangga
  • Univariate Baseline: Model dasar hanya menggunakan Global_active_power historis
  • Recursive Forecast Error: Forecast multi-step mengalami error accumulation
  • No Exogenous Variables: Cuaca, hari libur, musim tidak dimodelkan

Cara Menjalankan
  1. Install dependencies: pip install -r requirements.txt
  2. Letakkan dataset household_power_consumption.txt di folder energicast/data/raw/
  3. Jalankan aplikasi: python run.py
  4. Buka browser: http://localhost:5000
  5. Ikuti alur: Data Explorer → Preprocessing → Model Training → Model Performance → Forecast
