Tentang LSTM & Workflow

Long Short-Term Memory (LSTM) adalah jenis Recurrent Neural Network (RNN) yang dirancang untuk mengatasi masalah vanishing gradient pada RNN konvensional.

LSTM memiliki cell state dan tiga gate (forget gate, input gate, output gate) yang mengontrol aliran informasi, memungkinkan jaringan belajar ketergantungan jangka panjang dalam data sequential.

Dalam EnergiCast, LSTM digunakan untuk memprediksi Global_active_power berdasarkan sequence historis konsumsi listrik.

  1. Load Data: Baca dataset household power consumption (per menit)
  2. Preprocessing: Parse timestamp, handle missing, agregasi ke hourly
  3. Split Kronologis: 70% train, 15% val, 15% test (tidak random)
  4. Scaling: Fit scaler hanya pada train, transform val/test
  5. Windowing: Sliding window (default 24 timesteps) → target next step
  6. Model: 1 LSTM layer (32 units) → Dense(1), MSE loss, Adam optimizer
  7. Training: Early stopping (patience=5), restore best weights
  8. Evaluasi: MAE, RMSE, MSE pada test set (inverse transform ke unit asli)
  9. Forecast: Recursive multi-step prediction untuk horizon masa depan

  • Univariate baseline: Hanya menggunakan Global_active_power historis, tidak memanfaatkan fitur lain (voltage, intensity, sub-metering)
  • Recursive forecasting: Error accumulation semakin besar pada horizon panjang
  • No exogenous variables: Cuaca, hari libur, musim tidak dimodelkan
  • Single household: Dataset hanya satu rumah tangga, tidak generalisasi ke populasi
  • Stationarity assumption: Tidak ada differencing atau detrending eksplisit
  • Baseline configuration: Hyperparameter default tidak dioptimalkan (untuk demo/learning)
